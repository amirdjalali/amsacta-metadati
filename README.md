This repository contains a documentation of the mapping of the metadata of [AMS Acta](https://amsacta.unibo.it), the institutional repository of the University of Bologna, to [DataCite 4.6](https://datacite-metadata-schema.readthedocs.io/en/4.6/) and [OpenAIRE 4.0.0](https://openaire-guidelines-for-literature-repository-managers.readthedocs.io/en/v4.0.0/).

The documentation is written in Markdown and converted into a minisite by using the theme [Material](https://squidfunk.github.io/mkdocs-material/) for [MkDocs](https://www.mkdocs.org/).

It was compiled on a linux machine using Python 3.10.18.

It uses ```mkdocs``` version 1.6.1, ```mkdocs-material``` version 9.6.21, ```mkdocs-to-pdf``` version 0.10.1.
